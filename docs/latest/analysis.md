## 長期與市場狀態穩定性

事先固定：多頭＝當時收盤≥200 日均線；空頭＝收盤<200 日均線。高波動＝自身20日年化波動≥之前756交易日的75分位數（至少252筆，門檻延後一日）。高／一般波動與多／空頭是兩種重疊分類，不可相加樣本數。這是技術狀態標籤，不是官方景氣循環或事後高低點。

比較從 2020 年初開始；預測日期以固定起點每隔 h 個交易日取樣，新增一天不會重新排列歷史測試日期。每次只用當時成熟的標籤訓練。

穩定候選需同時滿足：整體MAE至少改善1%、95%下界>0、42次整體比較Holm校正p<0.05；多頭、空頭、高波動、一般波動及2024年前／後各至少20次且皆改善；至少5個完整起點年度，且至少2/3年度改善。這些是研究篩選規則，不保證未來；2024年後資料曾在前次研究中檢視，不是全新保留測試集。未達標不等於指標永遠無用。

## 三地大盤 PCA

以 2023-07-27 至 2026-11-09 的 756 個共同日期之標準化對數報酬分析。PC1／PC2／PC3 解釋變異比例為 57.8% / 33.0% / 9.3%。

權重是統計主成分係數，並非成分股持股比例。PCA 只描述共變動，不證明因果。同一日期的台股比北美先收盤，相關矩陣不代表同步交易資訊；跨市場 PCA 未被用作預測特徵。

## 方法與限制

KD 使用台灣遞迴式 (9,3,3)，K、D 初始值皆 50；K 超過 80 是高檔動能，不能單獨推出即將下跌。RSI(14) 與 ATR(14) 採 Wilder 平滑。模型為 StandardScaler → PCA(90% 變異) → Ridge(alpha=10)，每次僅在歷史訓練集擬合，訓練標籤結束日嚴格早於預測起點。

模型自 2020 年初開始評估，發布前要求實際樣本外跨度至少五年，每隔 h 日預測 h 日報酬，因此評估區間不重疊。指數成交量品質因供應商而異，不用於模型。未加入新聞、成分股權重、交易成本或可成交策略績效；本報告為研究用途，不構成買賣建議。
